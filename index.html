시작 안내

이번 미션은 PC에서 진행하면 편합니다. 요청 만들기 → HTML 저장·실행 → 수정하고 비교하기 순서로 나만의 업무 도구를 만들어 봅니다.

AI는 우리가 어떤 업무를 하는지, 무엇이 불편한지 모릅니다. 상황과 원하는 동작을 알려주면 만들 페이지의 모습이 더 분명해져요.

이렇게 구체적으로 알려 주세요

“영문 주소 도우미를 만들어 줘”에서 한 걸음 더.
“직원이 확인한 영문 이름과 주소를 입력하면, 전표 크기로 출력해 고객에게 드릴 수 있게 해 줘.”

불편한 상황 → 만들 도구 → 사용자 → 입력할 정보 → 동작과 결과 → 화면과 확인 기준. 여섯 질문으로 정리합니다.

직접 요청문을 쓰거나 도우미를 이용하세요. 막히면 아래 ‘예시 요청문 보기’를 펼쳐 참고할 수 있습니다.

  1. 필요한 경우 선택한 서비스에 로그인하세요.
  2. 새 대화의 입력창에 복사한 프롬프트를 붙여넣고 전송하세요.
    휴대폰: 입력창 길게 누르기 → 붙여넣기 · PC: Ctrl+V / Mac: ⌘+V
  3. 답변을 받은 뒤 이 안내 페이지로 돌아와 STEP 3을 진행하세요.
  1. AI에 요청 보내기
    위 도구 하나를 열고 로그인한 뒤, 새 대화에 복사한 요청문을 붙여넣으세요.
  2. HTML 파일 저장하기
    AI가 파일을 주면 내려받으세요. 코드만 받았다면 아래 방법으로 저장하세요.
    코드만 받았을 때 · 메모장으로 저장하기
    1. PC 메모장에 HTML 코드만 붙여넣으세요. 코드 앞뒤의 ``` 표시는 제외합니다.
    2. ‘다른 이름으로 저장’에서 파일 형식은 모든 파일, 인코딩은 UTF-8로 선택하세요.
    3. 파일명을 업무도우미.html로 저장하세요. 끝에 .txt가 붙지 않았는지 확인하세요.
  3. 브라우저에서 직접 써 보기
    저장한 HTML 파일을 브라우저로 열고 가상 정보로 입력·버튼·결과를 확인하세요. 불편한 점을 하나 찾아 STEP 3으로 이어가세요.
    회사 PC에서 실행이 제한되면 은행에서 허용한 환경을 이용하세요.
바로가기는 AI 사이트만 엽니다. 프롬프트가 자동으로 입력되거나 전송되지는 않습니다. 은행에서 허용한 도구를 사용하세요. 다른 AI 도구나 사내 AI를 이용해도 됩니다.
