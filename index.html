고객 안내 문자 만들기

고객의 방문 예약을 안내하는 문자 틀을 만들어 보세요.

실습 준비 · 모든 상황은 가상입니다. 대괄호는 그대로 두거나 가상의 내용으로 바꿔 주세요. 실제 고객정보·거래정보·내부자료는 입력하지 않습니다.
만들기 전, 생각 정리

AI에게 무엇을 알려주면 좋을까요?

시작 안내

AI는 우리가 어떤 업무를 하는지, 무엇이 불편한지 모릅니다. 상황과 원하는 동작을 알려주면 만들 페이지의 모습이 더 분명해져요.

이렇게 구체적으로 알려 주세요

“영문 주소 도우미를 만들어 줘”에서 한 걸음 더.
“직원이 확인한 영문 주소를 입력하면, 고객이 읽기 쉽게 크게 보여주고 복사할 수 있게 해 줘.”

불편한 상황 → 만들 도구 → 사용자 → 입력할 정보 → 동작과 결과 → 화면과 확인 기준. 여섯 질문으로 정리합니다.

답변은 짧은 문장으로 적어도 괜찮아요. 예시를 보고 내 상황에 맞게 바꿔 주세요.

미션 3 · HTML 페이지로 직접 만들어 보기
  1. 위 도우미의 질문에 답해 프롬프트를 만드세요. 바로 시작하고 싶다면 아래 STEP 1의 영문 이름·주소 도우미 예시를 그대로 사용해도 됩니다.
  2. AI에 프롬프트를 보내고 HTML 파일을 받으세요. 코드만 받았다면 PC 메모장에 코드만 붙여넣고, 파일 형식 ‘모든 파일’ · 인코딩 ‘UTF-8’ · 파일명 ‘업무도우미.html’로 저장하세요.
  3. 저장한 파일을 브라우저로 열고 가상 정보로 버튼과 화면을 확인하세요. 회사 PC에서 실행이 제한되면 은행에서 허용한 환경을 이용하세요.
  4. 불편한 점을 STEP 3에 적어 같은 AI 대화에 보내세요. 수정된 전체 HTML로 파일을 바꾸고 새로고침해 비교하세요.

이번 미션은 PC에서 진행하면 편합니다. 여기서는 시제품을 만들고, 실제 업무 반영은 은행의 보안·업무 기준에 따른 검토 후 진행하세요.

  2. 새 대화의 입력창에 복사한 프롬프트를 붙여넣고 전송하세요.
    휴대폰: 입력창 길게 누르기 → 붙여넣기 · PC: Ctrl+V / Mac: ⌘+V
  3. 답변을 받은 뒤 이 안내 페이지로 돌아와 STEP 3을 진행하세요.

바로가기는 AI 사이트만 엽니다. 프롬프트가 자동으로 입력되거나 전송되지는 않습니다. 은행에서 허용한 도구를 사용하세요. 다른 AI 도구나 사내 AI를 이용해도 됩니다.

추가 요청을 원하는 내용으로 수정한 뒤 복사해, 방금 사용한 AI의 같은 대화에 붙여넣으세요.

써 보니, 무엇을 바꾸면 좋을까요?

시작 안내

먼저 AI가 만든 HTML 파일을 열어 보세요. “잘 안 돼요”보다 사용한 환경, 했던 동작, 실제 결과를 알려주면 AI가 고칠 부분을 찾기 쉬워집니다.

이렇게 구체적으로 알려 주세요

“글씨를 키워 줘”에서 한 걸음 더.
“창구 PC에서 주소를 입력했는데 결과 글씨가 작아요. 결과를 28px 이상으로 키우고, 복사 버튼은 바로 아래에 놓아 주세요.”

사용한 환경과 동작 → 실제 결과 → 원하는 결과 → 유지할 부분. 네 질문으로 수정 요청을 만듭니다.
